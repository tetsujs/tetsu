# Code of conduct

Tetsu follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the repository — issues, pull requests, discussions — and
anywhere someone represents the project.

In short: be respectful and constructive, assume good intent, and keep
criticism about the work rather than the person. Harassment, insults,
personal attacks and publishing someone's private information are not
accepted.

To report a problem, write to [hello@tetsujs.com](mailto:hello@tetsujs.com).
Reports are read only by the maintainers and kept confidential. Behaviour
that breaks this code may lead to a warning, a temporary ban or a
permanent one, as the Covenant describes.
